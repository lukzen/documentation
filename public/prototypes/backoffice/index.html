Agency Remittances

Monthly amounts each agency owes Ergos. Mark Paid records a wire reference + audits the action. Adjusting an amount requires a reason.

Functionality In Development
The Agency Remittances module is not yet in production. Real backoffice finance/ module only ships BookingBreakdownPage. Flows being prototyped here:
  • Click an agency in the top table → bottom drilldown swaps to that agency's stats + audit trail
  • Click a KPI card (Outstanding / Overdue / Collected MTD) → list filters to that bucket
  • Sortable columns: Agency, Period, Amount, Status, Due, Last action
  • Per-row Modify Status (revert paid → pending with reason) + Adjust amount
  • Mark Paid records wire reference + writes to audit trail
