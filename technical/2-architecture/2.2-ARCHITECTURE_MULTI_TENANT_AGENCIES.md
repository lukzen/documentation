## Executive Summary

This document outlines the multi-tenant architecture for the OneClickAdventures platform, designed to support multiple travel agencies (initially 10, scaling to 100+) where each agency operates their own branded booking portal while sharing core infrastructure.

### Key Requirements

- Each travel agency has its own URL
- Shared hotels database (all agencies see the same hotels)
- Isolated bookings per travel agency
- Centralized payment processing via single TropiPay account (profit distribution handled externally)
- Same codebase for all agencies
- Easy onboarding of new agencies

### Two Implementation Approaches

This document presents **two distinct implementation approaches**:

| Approach | URLs | Best For | Complexity | Cost |
|----------|------|----------|------------|------|
| **A: Wildcard Subdomains** | `agency1.lukzen-op.com`<br>`agency2.lukzen-op.com` | Fast launch<br>10-50 agencies<br>Centralized control | Low | $1,200-1,900/mo |
| **B: Independent Domains** | `bookings.agency1.com`<br>`reservas.agency2.com` | White-label<br>Enterprise clients<br>Full branding | Medium | $1,220-1,920/mo |

**Recommended Starting Point:** **Approach A (Wildcard Subdomains)** for initial launch, migrate to Approach B when agencies request custom domains.

### Core Principles

1. **Single Shared Application**: One deployment handles all agencies
2. **Database-Level Multi-Tenancy**: Tenant isolation via `tenantId` field
3. **URL-Based Tenant Identification**: Different methods for each approach
4. **Centralized Payment Processing**: Single TropiPay account for all transactions (profit distribution managed externally)

## Database Design (Common to Both Approaches)

The database schema is **identical** for both approaches. Only the tenant identification method differs.

### Tenant Collection

```typescript
// src/models/tenant.model.ts
import mongoose, { Schema, Document } from 'mongoose'

export interface ITenantDomain {
  domain: string                    // e.g., "agency1.lukzen-op.com" or "bookings.agency1.com"
  type: 'subdomain' | 'custom'
  isPrimary: boolean
  verified: boolean
  verificationToken?: string
  verifiedAt?: Date
}

export interface ITenant extends Document {
  tenantId: string                  // tenant_001, tenant_002, etc.
  slug: string                      // agency1, agency2 (URL-friendly identifier)
  displayName: string               // "Travel Agency 1"
  email: string
  isActive: boolean

  domains: ITenantDomain[]          // Supports multiple domains per tenant

  settings: {
    primaryColor: string
    secondaryColor: string
    logoUrl: string
    faviconUrl: string
  }

  limits: {
    maxBookingsPerMonth: number
    maxUsers: number
  }

  subscription: {
    plan: 'free' | 'starter' | 'professional' | 'enterprise'
    status: 'active' | 'suspended' | 'cancelled'
    billingEmail: string
  }

  createdAt: Date
  updatedAt: Date
}

const tenantSchema = new Schema<ITenant>({
  tenantId: {
    type: String,
    required: true,
    unique: true,
    index: true
  },
  slug: {
    type: String,
    required: true,
    unique: true,
    lowercase: true,
    trim: true,
    match: /^[a-z0-9-]+$/,
    index: true
  },
  displayName: {
    type: String,
    required: true
  },
  email: {
    type: String,
    required: true,
    unique: true
  },
  isActive: {
    type: Boolean,
    default: true,
    index: true
  },
  domains: [{
    domain: { type: String, required: true },
    type: { type: String, enum: ['subdomain', 'custom'], required: true },
    isPrimary: { type: Boolean, default: false },
    verified: { type: Boolean, default: false },
    verificationToken: String,
    verifiedAt: Date
  }],
  settings: {
    primaryColor: { type: String, default: '#007bff' },
    secondaryColor: { type: String, default: '#6c757d' },
    logoUrl: String,
    faviconUrl: String
  },
  limits: {
    maxBookingsPerMonth: { type: Number, default: 1000 },
    maxUsers: { type: Number, default: 10 }
  },
  subscription: {
    plan: { type: String, enum: ['free', 'starter', 'professional', 'enterprise'], default: 'starter' },
    status: { type: String, enum: ['active', 'suspended', 'cancelled'], default: 'active' },
    billingEmail: String
  }
}, {
  timestamps: true
})

// Indexes for fast tenant lookup
tenantSchema.index({ tenantId: 1, isActive: 1 })
tenantSchema.index({ slug: 1, isActive: 1 })
tenantSchema.index({ 'domains.domain': 1 }, { sparse: true })

export const Tenant = mongoose.model<ITenant>('Tenant', tenantSchema)
```

# APPROACH A: Wildcard Subdomains

**Example URLs:**
- `agency1.lukzen-op.com`
- `agency2.lukzen-op.com`
- `agency3.lukzen-op.com`

**Best For:** Initial launch, fast deployment, centralized control, cost efficiency

**Complexity:** ⭐⭐ Low

**Onboarding Time:** Instant (no agency action required)

### Key Characteristics

✅ **Instant Setup:** New agency = new database record, works immediately
✅ **One SSL Certificate:** Wildcard cert covers all subdomains
✅ **Simple Tenant Detection:** Extract subdomain from URL
✅ **No Agency DNS Configuration:** Fully managed by you
✅ **Centralized Control:** You manage all DNS and SSL

⚠️ **Limited Branding:** All agencies share same root domain
⚠️ **No White-Label:** `lukzen-op.com` visible in URL

#### Step 3.1: Create Ingress with Wildcard Rule

```yaml
# k8s/agency-app/ingress-wildcard.yaml
apiVersion: networking.k8s.io/v1
kind: Ingress
metadata:
  name: agency-app-wildcard
  namespace: production
  annotations:
    # Use existing wildcard certificate
    cert-manager.io/cluster-issuer: "letsencrypt-prod"

    # Security headers
    nginx.ingress.kubernetes.io/ssl-redirect: "true"
    nginx.ingress.kubernetes.io/force-ssl-redirect: "true"
    nginx.ingress.kubernetes.io/ssl-protocols: "TLSv1.2 TLSv1.3"

    # Pass subdomain to backend
    nginx.ingress.kubernetes.io/configuration-snippet: |
      proxy_set_header X-Forwarded-Host $host;
      proxy_set_header X-Original-Host $host;

    # Rate limiting
    nginx.ingress.kubernetes.io/limit-rps: "100"
    nginx.ingress.kubernetes.io/limit-connections: "50"

  labels:
    app: agency-app
spec:
  ingressClassName: nginx
  tls:
  - hosts:
    - "*.lukzen-op.com"
    - "lukzen-op.com"
    secretName: wildcard-lukzen-op-tls
  rules:
  # Wildcard rule catches all subdomains
  - host: "*.lukzen-op.com"
    http:
      paths:
      - path: /
        pathType: Prefix
        backend:
          service:
            name: agency-app
            port:
              number: 80
  # Root domain (optional - could redirect to main site)
  - host: "lukzen-op.com"
    http:
      paths:
      - path: /
        pathType: Prefix
        backend:
          service:
            name: agency-app
            port:
              number: 80
```

### Phase 1: Frontend Changes (Week 1, Day 5-7)

#### Step 1.1: Update Tenant Detection Logic

```typescript
// src/utils/tenant.ts
export interface TenantConfig {
  tenantId: string
  tenantSlug: string
  displayName: string
  primaryColor: string
  logoUrl: string
}

// Hardcoded tenant registry (alternative: fetch from API)
const TENANT_REGISTRY: Record<string, TenantConfig> = {
  'agency1': {
    tenantId: 'tenant_001',
    tenantSlug: 'agency1',
    displayName: 'Travel Agency 1',
    primaryColor: '#007bff',
    logoUrl: 'https://cdn.lukzen-op.com/tenants/agency1/logo.png'
  },
  'agency2': {
    tenantId: 'tenant_002',
    tenantSlug: 'agency2',
    displayName: 'Travel Agency 2',
    primaryColor: '#28a745',
    logoUrl: 'https://cdn.lukzen-op.com/tenants/agency2/logo.png'
  }
  // Add more agencies as needed
}

/**
 * Extract tenant from subdomain
 * e.g., agency1.lukzen-op.com → agency1
 */
export const getTenantFromHostname = (): TenantConfig | null => {
  const hostname = window.location.hostname

  // Development: localhost → default tenant
  if (hostname === 'localhost' || hostname === '127.0.0.1') {
    return TENANT_REGISTRY['agency1'] || null
  }

  // Extract subdomain
  // agency1.lukzen-op.com → ['agency1', 'lukzen-op', 'com']
  const parts = hostname.split('.')

  if (parts.length >= 3) {
    const subdomain = parts[0]
    return TENANT_REGISTRY[subdomain] || null
  }

  return null
}

export const getCurrentTenant = (): TenantConfig => {
  const tenant = getTenantFromHostname()

  if (!tenant) {
    // Redirect to main site or show error
    window.location.href = 'https://lukzen-op.com/agencies'
    throw new Error('Invalid tenant or subdomain not found')
  }

  return tenant
}
```

#### Step 1.2: Add Tenant Context to Axios

```typescript

  (error) => Promise.reject(error)
)
```

```typescript
): Promise<void> => {
  try {
    // Get tenant from headers (set by frontend)
    const tenantId = req.headers['x-tenant-id'] as string
    const tenantSlug = req.headers['x-tenant-slug'] as string

    if (!tenantId && !tenantSlug) {
      throw new AppError(400, 'Tenant identification required', true, 'TENANT_MISSING')
    }

    // Fetch tenant from database
    const tenant = await Tenant.findOne({
      $or: [
        { tenantId },
        { slug: tenantSlug }
      ],
      isActive: true
    })

    if (!tenant) {
      throw new AppError(404, 'Tenant not found or inactive', true, 'TENANT_NOT_FOUND')
    }

    // Attach to request
    req.tenant = tenant
    req.tenantId = tenant.tenantId

    next()
  } catch (error) {
    next(error)
  }
}
```

```typescript
import axios from 'axios'
import { ITenant } from '../models/tenant.model'

export class TropiPayService {
  private baseURL: string
  private clientId: string
  private clientSecret: string

  constructor() {
    this.baseURL = process.env.TROPIPAY_SERVER_URL || 'https://tropipay-dev.herokuapp.com/api/v2'
    this.clientId = process.env.TROPIPAY_CLIENT_ID!
    this.clientSecret = process.env.TROPIPAY_CLIENT_SECRET!
  }

  // Get centralized credentials (same for all tenants)
  private async getAccessToken(): Promise<string> {
    const response = await axios.post(`${this.baseURL}/access/token`, {
      grant_type: 'client_credentials',
      client_id: this.clientId,
      client_secret: this.clientSecret,
      scope: 'ALLOW_PAYMENT_IN'
    })

    return response.data.access_token
  }

  async createPaymentLink(
    tenant: ITenant,
    bookingId: string,
    amount: number,
    description: string
  ): Promise<{ paymentUrl: string; orderId: string }> {
    const accessToken = await this.getAccessToken()

    // Include tenant information in payment metadata for tracking
    const response = await axios.post(
      `${this.baseURL}/paymentcards`,
      {
        reference: bookingId,
        amount,
        currency: 'USD',
        description: `${tenant.displayName} - ${description}`,
        // Metadata to track which agency the payment is for
        metadata: {
          tenantId: tenant.tenantId,
          agencyName: tenant.displayName
        }
      },
      {
        headers: {
          'Authorization': `Bearer ${accessToken}`
        }
      }
    )

    return {
      paymentUrl: response.data.paymentUrl,
      orderId: response.data.orderId
    }
  }
}
```

```typescript
// src/controllers/tenant.controller.ts
import { Request, Response } from 'express'
import { Tenant } from '../models/tenant.model'
import crypto from 'crypto'
import dns from 'dns/promises'

export class TenantController {
  // Request to add custom domain
  async addCustomDomain(req: Request, res: Response): Promise<void> {
    const { domain } = req.body
    const tenant = req.tenant!

    // Generate verification token
    const verificationToken = crypto.randomBytes(32).toString('hex')

    // Add domain to tenant (unverified)
    await Tenant.findOneAndUpdate(
      { tenantId: tenant.tenantId },
      {
        $push: {
          domains: {
            domain,
            type: 'custom',
            isPrimary: false,
            verified: false,
            verificationToken
          }
        }
      }
    )

    res.status(200).json({
      success: true,
      message: 'Domain added. Please verify ownership.',
      verification: {
        method: 'txt',
        record: {
          type: 'TXT',
          name: `_oneclick-verify.${domain}`,
          value: `oneclick-verification=${verificationToken}`
        }
      }
    })
  }

  // Verify domain ownership
  async verifyCustomDomain(req: Request, res: Response): Promise<void> {
    const { domain } = req.body
    const tenant = req.tenant!

    const domainConfig = tenant.domains.find(d => d.domain === domain)

    if (!domainConfig || domainConfig.verified) {
      throw new Error('Domain not found or already verified')
    }

    try {
      // Lookup TXT record
      const records = await dns.resolveTxt(`_oneclick-verify.${domain}`)
      const verificationRecord = records.flat().find(r =>
        r.includes(domainConfig.verificationToken)
      )

      if (!verificationRecord) {
        throw new Error('Verification record not found')
      }

      // Mark as verified
      await Tenant.updateOne(
        {
          tenantId: tenant.tenantId,
          'domains.domain': domain
        },
        {
          $set: {
            'domains.$.verified': true,
            'domains.$.verifiedAt': new Date()
          }
        }
      )

      // Trigger Ingress creation
      await this.createIngressForDomain(tenant, domain)

      res.status(200).json({
        success: true,
        message: 'Domain verified successfully'
      })
    } catch (error) {
      throw new Error('Domain verification failed')
    }
```

```typescript
// src/services/ingress.service.ts
import * as k8s from '@kubernetes/client-node'

export class IngressService {
  private k8sApi: k8s.NetworkingV1Api

  constructor() {
    const kc = new k8s.KubeConfig()
    kc.loadFromDefault()
    this.k8sApi = kc.makeApiClient(k8s.NetworkingV1Api)
  }

  async createIngressForDomain(tenantSlug: string, customDomain: string): Promise<void> {
    const ingress: k8s.V1Ingress = {
      apiVersion: 'networking.k8s.io/v1',
      kind: 'Ingress',
      metadata: {
        name: `agency-app-${tenantSlug}`,
        namespace: 'production',
        annotations: {
          'cert-manager.io/cluster-issuer': 'letsencrypt-prod',
          'cert-manager.io/acme-challenge-type': 'http01',
          'nginx.ingress.kubernetes.io/ssl-redirect': 'true'
        }
      },
      spec: {
        ingressClassName: 'nginx',
        tls: [{
          hosts: [customDomain],
          secretName: `${tenantSlug}-tls`
        }],
        rules: [{
          host: customDomain,
          http: {
            paths: [{
              path: '/',
              pathType: 'Prefix',
              backend: {
                service: {
                  name: 'agency-app',
                  port: { number: 80 }
                }
              }
            }]
          }
        }]
      }
    }

    try {
      await this.k8sApi.createNamespacedIngress('production', ingress)
      console.log(`✅ Ingress created for ${customDomain}`)
    } catch (error: any) {
      if (error.response?.statusCode === 409) {
        // Already exists, update it
        await this.k8sApi.replaceNamespacedIngress(
          `agency-app-${tenantSlug}`,
          'production',
          ingress
        )
        console.log(`✅ Ingress updated for ${customDomain}`)
      } else {
        throw error
      }
    }
  }

  async deleteIngressForDomain(tenantSlug: string): Promise<void> {
    try {
      await this.k8sApi.deleteNamespacedIngress(
        `agency-app-${tenantSlug}`,
        'production'
      )
      console.log(`✅ Ingress deleted for ${tenantSlug}`)
    } catch (error) {
      console.error(`Failed to delete Ingress for ${tenantSlug}:`, error)
    }
  }
}
```

```typescript
// src/utils/tenant.ts
export interface TenantDomain {
  domain: string
  type: 'subdomain' | 'custom'
  isPrimary: boolean
  verified: boolean
}

export interface TenantConfig {
  tenantId: string
  tenantSlug: string
  displayName: string
  domains: TenantDomain[]
  settings: {
    primaryColor: string
    logoUrl: string
    faviconUrl: string
  }
}

// Cache tenant configs (domain → tenant mapping)
let TENANT_CACHE: Map<string, TenantConfig> = new Map()

/**
 * Load all tenant configs from API on app initialization
 * Builds a domain → tenant mapping for fast lookup
 */
export const loadTenantConfigs = async (): Promise<void> => {
  try {
    const response = await fetch('https://api.lukzen-op.com/api/v1/tenants/configs')
    const data = await response.json()
    const tenants: TenantConfig[] = data.data

    // Build domain → tenant mapping
    TENANT_CACHE.clear()
    for (const tenant of tenants) {
      for (const domain of tenant.domains) {
        if (domain.verified) {
          TENANT_CACHE.set(domain.domain, tenant)
        }
      }
    }

    console.log(`✅ Loaded ${TENANT_CACHE.size} tenant domains`)
  } catch (error) {
    console.error('Failed to load tenant configs:', error)
    throw error
  }
}

/**
 * Get tenant from current hostname
 * Works for both custom domains and subdomains
 */
export const getTenantFromHostname = (): TenantConfig | null => {
  const hostname = window.location.hostname

  // Development
  if (hostname === 'localhost' || hostname === '127.0.0.1') {
    return Array.from(TENANT_CACHE.values())[0] || null
  }

  // Exact match (works for custom domains and subdomains)
  if (TENANT_CACHE.has(hostname)) {
    return TENANT_CACHE.get(hostname)!
  }

  return null
}

export const getCurrentTenant = (): TenantConfig => {
  const tenant = getTenantFromHostname()

  if (!tenant) {
    window.location.href = 'https://lukzen-op.com/error'
    throw new Error('Tenant not found for this domain')
  }

  return tenant
}
```

```typescript
  }
```

#### Step 2.2: Enhanced Tenant Middleware with Caching

```typescript
// src/middleware/tenant.middleware.ts
import { Request, Response, NextFunction } from 'express'
import { AppError } from '../errors/AppError'
import { Tenant } from '../models/tenant.model'
import { redis } from '../config/redis'

export const tenantMiddleware = async (
  req: Request,
  res: Response,
  next: NextFunction
): Promise<void> => {
  try {
    // Get from header (subdomain approach) OR hostname (custom domain)
    const tenantId = req.headers['x-tenant-id'] as string
    const hostname = req.hostname  // e.g., bookings.agency1.com

    let tenant: any

    // Try tenant ID from header first (faster)
    if (tenantId) {
      tenant = await getTenantById(tenantId)
    } else {
      // Fall back to domain lookup (custom domains)
      tenant = await getTenantByDomain(hostname)
    }

    if (!tenant || !tenant.isActive) {
      throw new AppError(404, 'Tenant not found', true, 'TENANT_NOT_FOUND')
    }

    req.tenant = tenant
    req.tenantId = tenant.tenantId

    next()
  } catch (error) {
    next(error)
  }
}

// Helper: Get tenant by ID (with Redis cache)
async function getTenantById(tenantId: string): Promise<any> {
  const cacheKey = `tenant:id:${tenantId}`

  // Try cache
  const cached = await redis.get(cacheKey)
  if (cached) {
    return JSON.parse(cached)
  }

  // Query database
  const tenant = await Tenant.findOne({ tenantId, isActive: true })

  if (tenant) {
    // Cache for 1 hour
    await redis.setex(cacheKey, 3600, JSON.stringify(tenant))
  }

  return tenant
}

// Helper: Get tenant by domain (with Redis cache)
async function getTenantByDomain(domain: string): Promise<any> {
  const cacheKey = `tenant:domain:${domain}`

  // Try cache
  const cached = await redis.get(cacheKey)
  if (cached) {
    return JSON.parse(cached)
  }

  // Query database
  const tenant = await Tenant.findOne({
    'domains.domain': domain,
    'domains.verified': true,
    isActive: true
  })

  if (tenant) {
    // Cache for 1 hour
    await redis.setex(cacheKey, 3600, JSON.stringify(tenant))
  }

  return tenant
}
```

```typescript
// src/middleware/redirect.middleware.ts
export const redirectToCustomDomain = async (
  req: Request,
  res: Response,
  next: NextFunction
): Promise<void> => {
  const hostname = req.hostname
  const tenant = await getTenantByDomain(hostname)

  if (tenant) {
    // Find primary custom domain
    const primaryDomain = tenant.domains.find(
      d => d.type === 'custom' && d.isPrimary && d.verified
    )

    // If accessing via subdomain but custom domain exists, redirect
    if (primaryDomain && hostname !== primaryDomain.domain) {
      const newUrl = `https://${primaryDomain.domain}${req.originalUrl}`
      return res.redirect(301, newUrl)
    }
  }

  next()
}
```

## Summary

Both approaches are **production-ready** and **cost-effective**. The choice depends on your business model:

- **Start Fast, Prove Value:** Use **Approach A (Wildcard Subdomains)**
- **White-Label from Day 1:** Use **Approach B (Custom Domains)**
- **Best of Both:** Implement **Approach A** first, add **Approach B** later (hybrid model)

**Recommended Path:**
1. **Weeks 1-2:** Implement Approach A (wildcard subdomains)
2. **Weeks 3-4:** Launch with first 10 agencies
3. **Weeks 5-8:** Add Approach B (custom domain support) if agencies request it
4. **Month 3+:** Migrate high-value clients to custom domains, keep others on subdomains

This phased approach minimizes risk while providing a clear upgrade path.
